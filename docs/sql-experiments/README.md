# SQL Experiment Reports

This directory stores permanent reports produced by the SQL experiments defined in `../sql-strategy/experiments.md` and `../test-strategy/sql-experiments.md`.

Create a report only after executing an experiment. Each report should record:

- the related experiment ID;
- the prediction;
- schema and dataset conditions;
- SQL and execution method;
- observed result and query plan where relevant;
- explanation;
- resulting decision or next experiment.

Temporary command output and generated datasets are not stored here by default.
